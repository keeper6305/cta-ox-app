# 세무사 1차 OX · 전과목 (PWA)

세무사 1차 기출 선지를 O/X로 풀고 틀린 지문을 다시 내주는 모바일 학습 앱입니다.
서버·로그인 없이 브라우저 저장소(localStorage)만 사용합니다.

- 앱 주소: https://keeper6305.github.io/cta-ox-app/
- 수록: 1,574 O / 950 X — 총 2,524지문 (542문항)

| 과목 | 지문 | 범위 |
|---|---:|---|
| 세법학개론 | 595 | 2017·2021~2026 7개년 |
| 재정학 | 936 | 2017·2021~2026 6개년 · 8단원 |
| 행정소송법 | 778 | 2021~2026 6개년 · 22단원 |
| 회계학개론(말문제) | 215 | 2021~2026 6개년 · 21단원 |
| **합계** | **2,524** | |

## 화면

1. **데일리** — 과목 기준 하루 세트(10/20/30/40문항), 날짜+과목 시드로 고정, 30%는 오답노트에서
2. **과목·단원별 집중 풀기** — 4과목 58단원 × 10/20/30문항
3. **기출 회차별 풀기** — 26회차(세법 7 · 재정학 7 · 행소 6 · 회계 6) 중 골라서. 회차를 고르면
   그 시험의 문항을 번호 순으로 **한 문항 = 한 지문**씩 출제하고, 아직 안 푼 지문이 남은 문항을 먼저 냅니다.
   회차 전체(예: 세법 2026 제63회 21문항) 또는 10/20/30문항만 골라 풀 수 있고, 회차마다 정답률·커버리지가 표시됩니다.
4. **회차 답안지(📝)** — 한 회차를 O/X만 쭉 골라 두고 **한 번에 채점**. 결과에서 틀린 문항을 바로 해설로 확인합니다.
5. **오답노트** — 다시 볼 / **모름** / 해결됨 3탭, 오답 집중 출제, 해결 표시·되돌리기
6. **북마크** — 문제 화면 ☆ 저장 → 모아 보기, 북마크만 다시 풀기
7. **문제 검색** — 2,524지문의 문장·해설·조문·출처를 키워드로 즉시 검색
8. **모르겠음** — O/X 대신 넘기면 오답노트 「모름」으로 담깁니다(찍지 않고 넘기는 학습)
9. **내 메모** — 지문마다 한 줄 메모(기기에 저장), **🤖 AI에게 묻기** — 지문·정답·해설을 질문으로 복사
10. **해설 강조** — 조문(§)·금액·비율·「용어」를 자동 하이라이트, 2026 개정 카드
11. **기록·통계** — 스트릭·최근 7일·과목별/단원별 정답률·**회차별 진도**, JSON 백업/복원
12. **D-day** — 2027 세무사 1차 예상일(4/24)까지 남은 일수와 커버리지 진행률

## O/X 판정 원칙

기출 해설에는 정답 선지만 표시된 문항이 대부분이라, 선지별 O/X는 발문 논리 + 큐넷 최종정답으로 확정했습니다.

- `…으로 옳지 않은 것은?` → 정답 선지 = X, 나머지 = O
- `…으로 옳은 것은?` → 정답 선지 = O, 나머지 = X
- 계산·단답형, ㄱㄴㄷ 조합형, 복수정답 문항은 OX 지문으로 성립하지 않아 제외

O/X 판정은 **출제 당시 법령·기준**입니다. 세법학개론은 2026년 현행과 달라진 쟁점만 배지·개정 카드로 표시합니다.

## 갱신 방법

`index.html` 또는 `bank.js`를 교체해 이 저장소에 커밋하면 1분 안에 반영됩니다.
서비스 워커 캐시 이름(`sw.js`의 `CACHE`)을 함께 올려야 기존 방문자에게 새 파일이 전달됩니다.
